# Restarter — Minecraft 1.12.2 / SpongeForge (recovered source)

This repository contains a **decompilation-based recovery** of the CraftersLand Restarter Sponge plugin supplied as `Plugin-Restarter-1.21.3-7.2-jdbc-registration(1).jar`.

## Origin and scope

- Sponge annotation: plugin ID `restarter`, version `1.21.3`, author `brunyman`.
- Target runtime: Minecraft 1.12.2, SpongeForge / SpongeAPI 7.x, Java 8.
- The included legacy `plugin.yml` says version `1.18.11`, which conflicts with the Sponge annotation. This file is preserved only because it exists in the original JAR.
- The original JAR contained **51 Restarter class files** and a bundled, older MySQL Connector/J implementation (345 `com/` classes). The bundled third-party driver is deliberately **not** copied into this source repository.
- Application bytecode and the original configuration files are stored in `recovery/restarter-app-classes.b85` (a Base85-encoded, XZ-compressed tar archive).
- Source under `src/main/java` is generated by CFR 0.152 and therefore is **not identical** to the developer's original source: comments, some names and syntactic details may be lost.

## Recover the source

The GitHub Actions workflow `Recover Restarter Java Source` runs the script `tools/reconstruct_and_decompile.py`. It reconstructs the application class files, runs CFR, and commits Java source and resources to the repository.

To run locally, install Java 8+ and Python 3.8+, then:

```bash
python tools/reconstruct_and_decompile.py
```

The script downloads CFR 0.152 from Maven Central if it is not already cached in `tools/cfr-0.152.jar`, so network access is required. The packed recovery archive does not include the MySQL connector; it is intentionally excluded from version control. If you need to build the plugin, set up a Java 8 project with SpongeAPI 7.x, Minecraft Forge 1.12.2, and any needed mod/API dependencies. **A successful build and server behavior have not yet been verified.**

## Before modifying production

Review and test changes on a backup staging server, particularly multi-server database writes, scheduled restarts, and chunkloader persistence. The original default config includes example database credentials: do not use those defaults in production.

This recovery is intended as the baseline for subsequent fixes and maintenance, **not** a verified drop-in rebuilt JAR.
